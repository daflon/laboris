4
JWT + Formulário Longo

O que acontece se o usuário está preenchendo um formulário grande e o token JWT expira? Atualmente: perde tudo e é redirecionado pro login.

A) localStorage Draft
1. Usuário preenche form
2. Auto-save a cada 30s
3. Token expira → Login
4. Volta → Dados recuperados ✓

✓ Simples de implementar
✓ Funciona offline
⚠️ Dados ficam no navegador
Esforço: ~2h

B) Refresh Token
1. Login → JWT + Refresh
2. JWT expira em 15min
3. Refresh renova JWT
4. Sessão nunca "morre" ✓

✓ Experiência seamless
✓ Padrão da indústria
⚠️ Mais complexo (httpOnly cookie)
Esforço: ~3h

C) Aumentar Expiração
1. JWT expira em 24h
 
 
⚠️ Menos seguro

✓ Zero esforço
⚠️ Risco de segurança
⚠️ Token roubado vale mais
Esforço: ~5min

💡 Recomendação: Opção A (localStorage) resolve o problema imediato com baixo esforço. Refresh token pode vir depois se necessário.
